## 概述

本專案示範如何在 [Godot](https://github.com/godotengine/godot) 中整合像素字體 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)，並建立易於維護的本地化流程。

- 使用正確的字體匯入設定，保持像素字體在設計字號及整數倍字號下的清晰顯示。
- 透過 CSV 翻譯表管理介面和範例文字，建立易於維護的遊戲本地化工作流程。
- 支援在執行階段切換語言；更新本地化文字的同時，依語言或區域載入對應的字體資源，以正確顯示簡體中文、繁體中文、日語和韓語的同碼異形字。

範例保持實作簡潔，並遵循 Godot 的最佳實務。
