## Overview

This project demonstrates how to integrate [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) in [Godot](https://github.com/godotengine/godot) and establish a maintainable localization workflow.

- Use the correct font import settings to keep pixel fonts crisp at their design size and integer multiples.
- Manage UI and sample text with CSV translation tables to establish an easy-to-maintain game localization workflow.
- Switch languages at runtime, updating localized text and loading the appropriate font resource for each language or region to correctly display locale-specific glyph variants for Simplified Chinese, Traditional Chinese, Japanese, and Korean.

The sample keeps its implementation concise and follows Godot best practices.
