## 概述

本项目演示如何在 [Godot](https://github.com/godotengine/godot) 中集成像素字体 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 并建立可维护的本地化流程。

- 使用正确的字体导入配置，保持像素字体在设计字号及整数倍字号下的清晰显示。
- 通过 CSV 翻译表管理界面和示例文本，建立易于维护的游戏本地化工作流。
- 支持运行时切换语言，更新本地化文本的同时按语言或区域加载对应的字体资源，以正确显示简体中文、繁体中文、日语和韩语的同码异形字。

示例保持实现简洁，并遵循 Godot 的最佳实践。
